# Домашнее задание к занятию 3 «Резервное копирование» - Шаров Олег

### Задание 1

Команда `rsync` для создания зеркальной копии домашней директории в `/tmp/backup` с учётом всех требований:

```bash
rsync -av --delete --checksum --exclude='.*' ~/ /tmp/backup/
```

Пояснение флагов:

. -a — архивный режим (рекурсивно, сохраняет атрибуты)
. -v — подробный вывод
. --delete — удаляет файлы в приёмнике, которых нет в источнике (зеркало)
. --checksum — принудительно вычисляет хэш-суммы для сравнения
. --exclude='.*' — исключает все скрытые файлы и директории
